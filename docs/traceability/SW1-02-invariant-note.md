# SW1-02 invariant note

SW1-02 strengthens product-boundary evidence for INV-001, INV-002, INV-013, INV-015 and INV-030. It does not promote any invariant from `PARTIAL_GREEN` to full `GREEN`.

In particular, rendering a governed benchmark does not itself prove member savings; savings remains a post-fulfillment calculation against actual comparable member economics. Likewise, rendering an offer does not create committed demand or an obligation.
