# SW1-02 — Governed catalog, offers, benchmark display and sales windows

This slice turns the existing SW0 catalog/economics primitives into a bounded SW1 member-facing sales composition without creating a second source of canonical truth.

The member view is executable only while its governed sales window is open and its underlying listing and offer remain executable. Optional benchmark display is sourced from a governed benchmark valuation and preserves benchmark version and evidence lineage.

Sales-window configuration is consequential policy configuration and therefore requires an evaluated canonical authority grant. UI/admin access is not sufficient.

This slice does not create purchase obligations, initiate payment, promise inventory, or authorize production launch. Those remain later gates.
